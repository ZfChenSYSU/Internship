# CMB 1000 题中 E0 对、E5 错的 42 题复核

日期：2026-10-01。对应[1000 题结果报告](CMB_EVAL_RESULTS_1000.md)。本报告逐题复核固定样本中 **E0 正确、E5 错误**的全部 42 题，目的是定位检索资料与答题变化的关系。原始标准答案、题型和计分保持不变。

## 方法与判定口径

从 `predictions.jsonl` 按相同 `source_id` 配对筛出 42 题。用 E5 记录的 `evidence_chunk_ids` 回查 `corpus_v1` 的 SQLite 索引，保存完整题目、选项、各组答案和实际入选的子片段原文，见 `data/eval/results/cmb_test_1000_v2/regression_42_evidence.json` 与 `regression_42_evidence.md`。共回查 321 个按题目计的父节点位置，平均每题约 7.6 个。子片段可能有重叠；窗口文字未逐字符重建，因此下文只根据可核查的已入选片段判定，不把父节点中其他文字算作模型所见证据。

每题只归入一个**主要证据关系**，以便统计；可能同时存在其他问题。这些是人工定性标签，不是模型内部因果解释，也不是医学标准答案的独立裁定。

## 语料覆盖与检索定位

另对索引全部 46,516 条可检索子片段做**精确字串**查询。该查询只说明字面是否存在，不能证明概念完全缺失，也不能测 Recall@K。几项有诊断价值的对照：

- ID 8656：其他皮肤病片段提到 Paget 病可发生在外生殖器，但 E5 窗口集中在股癣，优先查召回和重排。
- ID 1240：“惊悸”在整个索引仅命中 1 个片段，且只是方剂适应证；E5 入窗 0，说明既有语料薄弱，也有“惊悸/惊厥”的词面误召回。
- ID 2332、3206、4345、6796、9225、9245：各题核心短语（如“护士执业注册”“Ⅳ类环境”“中药一级保护”“发芽法”“五辨”“天气通于肺”）在索引子片段中精确命中 0 次，提示覆盖缺口；不能仅凭零命中断言同义表述不存在。
- ID 11072、11101、11188：胡椒、贯众、藜芦各有少量索引命中，但回查内容并未给出题目所需功效或配伍判据。单纯增加 Top-K 未必有用。
- 8/42 道题的某些入选片段共享明显不合主题的元数据路径“毛果芸香碱经典的常见眼局部副作用包括”，跨越方剂、中药等内容。应回查原文解析和章节路径构建；目前不能据此量化对准确率的影响。

## 对“基线最高”的判断与下一步

42 道退化题中，**25 道**属于 W/T/N，E5 窗口没有提供足够且可靠的区分信息；**8 道**已有可用标准项证据却仍答错；**7 道**证据混杂；**2 道**先要处理题库标注。它们共同解释了“有检索却降分”的具体路径，但这些类别是观察到的证据状态，不能据此给检索、模型和题库分配严格因果比例。

建议先在开发集上做三项可检验的改动：① 修复明显错位的章节元数据并标注来源版本，尤其排查复苏指南冲突；② 针对试题构造“题干核心概念 + 必要限定条件”的检索查询，并检查 Top-K/重排后是否保留区分片段；③ 让答题提示明确比较每个候选项与证据的支持和反证，证据无判据时降低其权重。**这 42 道来自测试集，适合诊断，不宜据此调参后再用同一批题宣称提升。**应在 CMB-val 或另建开发集调参，并用新的冻结测试子集验证。

敏感性核查：仅排除官方答案明显冲突的 ID 7621，E0 为 904/999（90.49%），E5 为 879/999（87.99%），差值仍约 −2.50 个百分点。主报告的 90.5% 与 87.9% 不作事后修订。
