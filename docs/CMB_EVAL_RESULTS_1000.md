# CMB-Exam 固定 1000 题 E0–E7 正确率与错题抽样报告

日期：2026-10-01。对应[测试方案](PUBLIC_BENCHMARK_ACCURACY_PLAN.md)和[运行说明](CMB_EVAL_RUNBOOK.md)。这是 **CMB-test 的固定随机 1000 题子集**，不是 11,200 题全量成绩。本轮只评价选择题答案，不评价幻觉、引用支持或临床安全性。

## 运行与计分口径

- 数据来自 [CMB 官方仓库](https://github.com/FreedomIntelligence/CMB)，修订 `6c8ece46097dae736c6805dd3b831e1a38c08971`。从 11,200 道 CMB-test 题中以 `random.Random(20260930).sample` 固定抽取 1000 题；题目 ID、数据/代码/语料哈希记录在 `data/eval/results/cmb_test_1000_v2/manifest.json`。1000 题含单选 888、多选 112，134 题有原始空白选项文本。抽样未按题型或科目分层。
- 全组使用 `deepseek-flash`、`temperature=0`、关闭 thinking、`cmb_accuracy_v2` 提示词与同一个 `corpus_v1` 索引。E0 无检索；E1 Dense；E2 BM25；E3 RRF 融合；E4 加 BGE 重排；E5 加父节点上下文；E6 在 E5 后由同一模型自检；E7 在 E6 后允许同一模型自主拒答。E6、E7 各增加一次模型调用。
- 单选必须是一个有效选项；多选按完整选项集合匹配。无效输出、拒答和 API 失败保留在 1000 题分母。全部 8000 个“题目 ID × 组别”记录齐全且唯一：有效作答 7982、格式无效 18、API 失败 0、拒答 0；全部 `finish_reason=stop`。
- 1000 题包含此前固定 100 题的全部 ID。为避免重复付费，从原运行复用 792 条逐题响应；8 条重叠响应采用本次新结果，其余 7200 条为本次新调用。本次新增调用合计 7208 次。导入前比对了除 `selected_ids` 外的 manifest 配置，来源文件 SHA-256 和数量保存在 `reuse_log.json`。因此两个报告的 100 题重叠部分有 8 条可能不同，**100 题与 1000 题不是独立样本**。

直接比较主流水线 E5 与无检索 E0：16 题错→对、42 题对→错，净差 **−2.6 个百分点**；同题配对 bootstrap 区间约 [−4.1, −1.1] 个百分点。当前配置下，检索流水线未提高这个固定子集的正确率。E5→E6 的净增益只有 4 题，E6→E7 只有 1 题，均不足以据此声称自检或自主拒答稳定有效。

## 从 E5 错题中固定抽样复核

E5 有 **121** 道错题，按 `random.Random(20261001)` 对这 121 个 ID 均匀抽取 **12** 道，占 **9.9%**；含单选 10、多选 2。抽样方法、题目、各组答案及按日志 `chunk_id` 回查的父节点摘要保存在 `data/eval/results/cmb_test_1000_v2/error_sample.json` 和 `error_sample_dossier.md`。以下“可能原因”基于题干、模型输出和已记录证据，是人工排错判断，**不是模型的真实推理过程，也不能外推成 121 道错题的原因比例**。

| ID | 标准 / E0 / E5 | 复核观察与可能原因 |
| --- | --- | --- |
| 3300 | C / A / A | 题干同时出现“合理的、适用的”，A 和 C 均有字面吸引力；检索片段未给出“适用性”的明确判据。更像题意辨析与证据缺口，无法单独归因于检索。 |
| 4564 | B / A / A | 问“无羧基的非甾体抗炎药”。检索证据提到吡罗昔康、对乙酰氨基酚，但未说明羧基结构；模型可能把“无羧基”当成唯一筛选条件，忽略药物类别。 |
| 5410 | B / D / D | 问热原检查法何者“不正确”；D 称鲎试验是“体内方法”，与鲎试剂和样品在实验条件下反应的步骤不符。北京市药监局指南还记载特定注射用水可用鲎试剂法检查、阳性须兔法复查。故**标准答案 B 与 D 至少存在单选争议**；保留原始计分，待题源人工核定。[北京市药监局指南](https://yjj.beijing.gov.cn/yjj/ztzl48/ylqxjgfwzn/jdjczn61/10957344/index.html) |

## 资源用量与解释边界

8000 条逻辑调用的 API 回传 `total_tokens` 合计 **18,970,249**；其中 E0 为 171,957，E5 为 3,679,926，E6 为 3,711,973，E7 为 3,719,973。E5–E7 较高的 token 用量主要来自父节点上下文和后续复核提示。各组单次 API 耗时中位数约 0.65–0.69 秒、P95 约 0.95–1.08 秒；这些是请求耗时，不含检索和重排的全流水线耗时。token 是 **1000 题完整结果对应的逻辑调用统计**，包含复用记录，不能等同于本次新增账单。

本结果只针对公开 CMB-test 固定子集、当前中文 `corpus_v1`、模型和提示词。公开试题可能已进入模型预训练；当前语料覆盖各考试科目不均。一次 `temperature=0` 运行仍可能有服务端波动。1000 题未分层抽样，分类别结果只用于排错。[E0 对而 E5 错的 42 道题已逐题复核](CMB_EVAL_REGRESSION_AUDIT_42.md)；后续改动需在开发集上调试，再用新的冻结测试子集复测。不要据此推断 RAG 在其他任务上普遍无效。

原始逐题记录、汇总与抽样档案在 `data/eval/results/cmb_test_1000_v2/`，该目录被 `.gitignore` 排除。`scripts/analyze_cmb_errors.py` 可按固定种子复现错题抽样；`summary.json`、`comparisons.json` 可复核上表。
